# Context index

Open a file only when the task needs it.

| File | Read it when |
|---|---|
| `../prd/README.md` | You need the requirements behind a ticket. |
| `static-export-notes.md` | You touch build, routing, metadata, content, theme, fonts or CI. |
| `pages.md` | You add or edit a page, metadata, the sitemap or robots, the social image, or replace placeholder copy. |
| `blog.md` | You add a post or touch the blog engine, sitemap or fixture. |
| `code-style.md` | You touch lint or format config, add or remove a lint rule, or wonder why a rule or Prettier setting exists. |
| `skills-source.md` | You need to know which version of the shared skills this repo uses. |

Testing and deployment notes are added here as tickets land.
